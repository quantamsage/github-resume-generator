How it works

  1. Analyze. We fetch your public profile and repositories from the GitHub API. No sign-in needed.
  2. Choose. Pick the projects that best represent you, and add details GitHub can't show, like contact info, experience and a target job.
  3. Generate. The AI writes a headline, summary, skills and project bullets using only evidence from your repositories. Anything it infers is clearly labelled.
  4. Edit & export. Edit every section, pick a template and download a print-ready PDF.

The AI never invents employers, degrees, certifications or metrics. Stars and commit counts are not treated as proof of skill.
